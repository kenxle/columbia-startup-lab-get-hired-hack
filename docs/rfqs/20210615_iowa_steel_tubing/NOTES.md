# State of Iowa RFQ 245 (DB22245005), 2021

- **Source:** [State of Iowa bid opportunities](https://bidopportunities.iowa.gov/Home/GetBidOpportunityDocument/e7ca77d0-dcf9-41e7-ad5c-dc15cca2a45e). Public solicitation. The PDF here is the copy the research saved on 2026-10-10 (`docs/research/.../verification_docs/iowa2021.pdf`).
- **Date:** issued 2021-07-16.
- **Buyer type:** state government (Iowa DOT shop supplies).
- **File:** `iowa_rfq_2021.pdf`, 49 numbered lines, each with a short name and a longer description that do not always agree.

## Why it is interesting

- **Positional shorthand changes meaning by product form.** "Strips 3 x 20 x 1/8"" is 3 in wide, 20 ft long, 1/8 in thick; "Structural Angle 3 x 3 x 1/4" is inches throughout with the 20 ft length only in the detail line; "RectangleTubes 2 x 1.5 x 24 x .120" puts feet third and a decimal wall fourth.
- **Two specs on one line:** "Square Tube A513-A500 Grade B" names mechanical and structural tube together (test line T3).
- **Gauge on stainless:** "Stainless Steel Sheets Type 304-2B, 48" x 120" long x 16 Gauge" (test line T1) and "60" x 120" x 14 Gauge".
- **Expanded metal by gauge:** "Expanded Stainless 48" x 96" x 13 GA x 1 1/2" Diamond" has no thickness we can look up (T4): the right answer is a question, not a lookup.
- **Spec quality terms fused to grades:** "Hot Rolled Strips CQ-A36".
- No mill test report, certification or origin requirement is written anywhere; the only origin wording is a tie-break preference for Iowa products.

Lines T1 to T7 of the research test set come from this document (`docs/research/20261010.01_rfq_sharper_angle/research_domain_rules.md`, section 6).
