## Using the data

Use `data/aviation/catalog.json` for matching and `price_observations.json` for source evidence. Match the complete AN part number, including A and C suffixes. Do not substitute drilled and undrilled shanks. RFQ aliases and examples are synthetic test inputs, not observed customer requests.

A matched public price does not make a quote ready. Ask for order quantity, delivery terms, certificate and origin requirements. Compare the same quantity tier and charges before explaining competitiveness. Cost and target margin are still missing, so suggested quote prices remain null.
