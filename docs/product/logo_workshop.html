Logo Workshop: RudCo Quote Desk

A working page for picking the favicon and the logo with Ken. Comment on any option. Every option uses RudCo's own mark exactly as rud-co.com serves it: no redraw, no recolor. The type is the site's system sans, at the weights the style guide sets.

Decision

Use RudCo's own mark, unchanged, for both the favicon and the logo (Ken, 2026-10-10). Nothing is redrawn and no new Quote Desk symbol is made. The favicon is the file rud-co.com uses for its own favicon. The header keeps the lockup the style guide describes.

Questions for you

Q1. Favicon: RudCo's mark as it is (F1)? That is your suggestion, and Claude agrees. It is the same file rud-co.com uses as its own favicon, so a Quote Desk tab looks like part of RudCo.
Q2. Which logo lockup (L1 to L4)? Claude recommends L1: it reads as a RudCo product, and "Quote Desk" stays clearly secondary.
Q3. The style guide currently says "Do not build a Quote Desk logo." Once you pick, Claude changes that rule to describe the chosen lockup, and posts it to Hirsh.

RudCo's mark

rud-co.com uses one mark everywhere: three faceted bars, like cut ingots, in a dark circle. The favicon, the header image, the footer image and the share image are the same 500 by 500 PNG artwork.

Rules every option keeps

  • RudCo's mark is used as the site serves it. Never redrawn, recolored, stretched, or traced.
  • The mark's height matches the header's 32 px. Words sit centered on it.
  • No new symbol for Quote Desk. The product is part of RudCo's service, so it borrows RudCo's identity.
  • Type is the system sans: 600 for RudCo, 500 for Quote Desk, per the style guide.
